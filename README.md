# aGo Monitor

Lightweight WordPress health monitor: SSL expiry, DB size, disk usage, autoloaded options, cron health, pending updates, 404 log, weekly email report. **Free, no Pro tier.**

[English](#english) · [Español](#espanol)

---

## English

aGo Monitor provides at-a-glance site health from the WordPress admin: SSL certificate expiry, database size, disk usage, autoloaded options weight, cron health, pending plugin updates, recent 404 errors.

### Features

- SSL certificate status and days until expiry.
- Database size and table count.
- Uploads and total disk usage.
- Autoloaded options size warning.
- Cron health: total events, overdue.
- Pending plugin updates count.
- 404 error log (last 7 days).
- Optional weekly health report by email.
- No external services. Checks run locally.
